# CodeAlpha Python Internship Projects

## Project 1: Basic Chatbot

### Description
A simple rule-based chatbot developed using Python. The chatbot responds to predefined user inputs and ends the conversation when the user types "bye".

### Features
- Greets the user
- Responds to common questions
- Rule-based conversation
- Easy to use

---

## Project 2: Stock Portfolio Tracker

### Description
A Python program that calculates the total investment based on the stock selected and the quantity entered by the user.

### Features
- User enters stock name and quantity
- Calculates total investment
- Displays investment details
- Saves the result in `investment.txt`

---

## Technologies Used
- Python 3

## Files Included
- chatbot.py
- stock_portfolio_tracker.py
- README.md

## How to Run
1. Open the project in Python IDLE or VS Code.
2. Run either `chatbot.py` or `stock_portfolio_tracker.py`.
3. Follow the instructions shown on the screen.
