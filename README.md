# Stock Portfolio Tracker

## Project Description
This is a simple Python project developed for the CodeAlpha Python Internship.

## Features
- User can enter stock name.
- User can enter stock quantity.
- Calculates total investment.
- Saves total investment in a text file.
- Easy to use and beginner-friendly.

## Technologies Used
- Python 3

## How to Run
1. Open the project in Python IDLE.
2. Run the file.
3. Enter the stock name and quantity.
4. Type "done" to finish.
5. The program displays the total investment and creates an investment.txt file.
